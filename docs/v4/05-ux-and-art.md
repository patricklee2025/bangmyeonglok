# 05 · UX · 화면 배치 · 문구 · 픽셀 아트 · 소리

> 기능 18개가 한 화면에 몰려도 **하객 입장에서는 여전히 단순**해야 합니다 (P8).
> 그래서 "어디에 무엇이 나올 수 있는지"를 미리 정해 두고(존/순서), 기능은 자기 자리에만 나옵니다.
> 레이아웃 감사(core-layout, core-features-matrix)가 겹침 0을 강제합니다.

## 1. 화면별 원칙

| 화면 | 누가 · 어디서 | 원칙 |
|---|---|---|
| 하객 폰 (index) | 하객 50명, 식장 입구 QR · 테이블 카드 | 방명록 4단계는 **절대 늘리지 않음**. 기능은 완료 화면 허브·환영 슬롯·별도 화면으로만 |

## 2. TV HUD 존 (village.html · HOST)

HUD는 지도(480×272 월드 픽셀) 크기에 딱 맞춰 늘어납니다. CSS 단위 `calc(var(--s) * Npx)` = 월드 N픽셀.
1920×1080 TV에서 `--s` ≈ 3.97 (월드 1px ≈ 화면 4px).

```
┌──────────────────────────────────────────────────────────────────────────┐
│ [Lv 패널 92w] ← 코어          [tc: 한 줄 공지·큐 제목 ≤200w]     [QR 42w] ← 코어 │
│ [tl: ≤92w]                                                     [tr: ≤60w]  │
│  · D-day 카운트(WP-03)                                          · 마음 온도계 │
│                                                                  (WP-08)     │
│                         ┌───────────────────┐                ┌──────────┐ │
│                         │  스포트라이트(가운데) │                │ rm: ≤110w │ │
│                         │  폴라로이드·스토리·   │                │ · 투표 패널 │ │
│                         │  엽서 — 한 번에 하나 │                │ · 빙고 순위 │ │
│                         └───────────────────┘                └──────────┘ │
│                    [배너: 바닥 20 위, 가운데] ← 코어 (큐)                       │
│ [티커 13h: 아바타 · 이름 · 메시지 / 둘째 줄 = 번역(WP-06)] ← 코어                  │
└──────────────────────────────────────────────────────────────────────────┘
```

| 존 | 위치 (월드 px) | 최대 크기 | 누가 쓰나 | 규칙 |
|---|---|---|---|---|
| `tl` | top 26, left 3 | 92w × 60h | WP-03 dday (pre) | pre 외에는 비어 있음 |
| `tr` | top 56, right 3 | 60w × 60h | WP-08 meter (live) · WP-14 추억 마을 명판 (아카이브 모드, QR 대신) | QR 숨김(Q 키)이면 위로 붙음 |
| `rm` | right 3, top 118 ~ bottom 40 | 110w | WP-10 poll(우선) · WP-09 bingo 순위 | 둘 다 있으면 투표가 위, 빙고는 접힘 |
| `tc` | top 3, 가운데 | 200w × 14h | WP-05 큐 제목 · `live.msg` 공지(WP-05, 제목보다 우선) | 한 줄, 넘치면 말줄임 |
| 가운데 | 스포트라이트 | 46% 너비 | 코어 폴라로이드 · WP-04 스토리 · WP-17 엽서 · WP-12 네컷 | 이벤트·조용 모드 중 대기, 7초 표시 |
| 티커 둘째 줄 | 티커 안 | 1줄 | WP-06 번역 (`setTickerExtra`) | 원문과 다른 언어일 때만 |
| 티커 앞머리 | 티커 첫 줄 맨 앞 | 짧은 글 (≤ 16자) | WP-18 1주년 "1년 전 오늘 · " (`setTickerPrefix`) | anniversary 페이즈만 |

배너 큐 (WP-00c 개선): `priority: 'high'`(식순·레벨업·부케 결과·빙고)는 일반(도착·스냅) 앞에 끼움.
도착 배너가 3개 이상 밀리면 "🎉 민준님 외 2명이 도착했어요!"로 합침. 조용 모드 중에는 보류 → 끝나면 합쳐서 1개.

### 3.2 폰 마을

```
┌─────────────────────────┐
│[Lv 패널]   [tc 칩]  [⛶] │  tc: "🤫 본식 진행 중"(조용 모드) · D-day(pre)
│[tl]                 [🗺] │
│                     [📍] │
│                          │
│        (마을 지도)         │
│                          │
│     [배너 — 하단 바 위]     │
│[❤️][👏][💃][⬆️][👋][📷][★]│  ★ = 기능 액션 자리 1칸 (1개면 그 기능, 2개 이상이면 order 최소 1개 + "⋯")
│[티커]                     │
└─────────────────────────┘
```
기능 액션 order: 🗳 투표 10 (열린 투표 있을 때만) · 📖 방명록(아카이브 모드) 15 · 🎯 빙고 20 · 💌 방명록 모아보기 25 (WP-19, 이 폰이 쓴 하객일 때) · 🃏 카드 30 · 📺 마을 TV 35 (WP-20, 당일·주소 있을 때) · ✉️ 엽서 40 · 📖 우리 이야기 45 · 🎂 1주년 50.
시트는 한 번에 하나: 기능 시트(`#fsheet`)를 열면 사진 시트(`#snap-sheet`)는 닫힘.

기억된 하객이 없는 폰(마을 주소를 그냥 연 사람): 하단 바 = 코어 `[✍️ 방명록 쓰기]` 링크(남은 너비) + `[★]` 기능 자리 1칸(같은 규칙).
```
│[✍️ 방명록 쓰기 ─────────][★]│     아카이브 모드: 링크는 숨김(쓸 수 없음) → [★]만
```

코어 요소를 숨기거나 옮겨야 하는 기능(WP-14 아카이브, WP-18 새 방문자 막기)은 `ctx.rootClass()` + 자기 CSS `html.f-<id>-<name> …`만 사용 (02 §3 규칙 4).

## 4. 문구 (KO/EN)

### 4.1 말투
- 한국어: **해요체**, 따뜻하고 짧게. 명령보다 안내 ("눌러주세요" ✓ / "누르시오" ✗). 어르신도 읽기 쉬운 말 ("동기화" → "연결", "업로드" → "올리기").
- 영어: 쉬운 단어, 짧은 문장, 문화 고유어는 설명 ("Pyebaek (Korean family ceremony)"). 느낌표는 화면당 1개 이내.
- 버튼·제목 앞에 이모지 1개 (훑어보기 쉽게). 본문 문장에는 남발 금지.
- 오류: "무슨 일 + 어떻게 하면 되는지" ("인터넷이 잠깐 끊겼어요. 연결되면 자동으로 보낼게요").
- 하객 이름 뒤 존칭: KO `{name}님` / EN 이름 그대로.
- 숫자·날짜: KO `4월 10일 (토)`, EN `Sat, Apr 10`. 시간 KO `오후 5:30`, EN `5:30 PM`.

## 6. 성능 (TV 노트북 · 폰)

- `onUpdate`/`onDraw`/`decorate`/`onOverlay`는 매 프레임: **할당 금지**(새 배열·객체·캔버스), 주민 수에 비례하는 이상 금지.
  무거운 계산은 데이터가 바뀔 때 1번 하고 캐시.
- 캔버스 이미지(소품·카드)는 한 번 만들어 재사용 (scene.js의 `critterCache` 방식).
- 오버레이 글자 측정(`measureText`)은 캐시 (village.js `wrapCache` 참고).
- 목표: 하객 50명 + 모든 기능 켜기에서 TV ≥ 24fps(헤드리스 기준), 실제 노트북 60fps.

## 7. 소리

- **BGM은 기본 꺼짐** (식장 음향과 충돌). 관리자가 WP-07 설정에서 켬. TV에서만 재생. 폰은 소리 없음.
- 효과음 볼륨 상한: Gain 0.06 (코어 차임과 같은 수준). 조용 모드·`M` 꺼짐이면 무음.
- 브라우저 정책: 첫 사용자 동작(클릭/키) 후에만 소리 — `ctx.v.onGesture`.
- 음악은 공개 저작물(Wagner 「Bridal Chorus」, Mendelssohn 「Wedding March」, J. Strauss II 「An der schönen blauen Donau」, Pachelbel 「Canon」)과 자작 루프만. 음원 파일 없이 WebAudio로 합성.

## 8. 접근성 · 어르신 · 키오스크

- 터치 대상 ≥ 44px 권장 (자동 검사는 32px 이상 강제). 아이콘 버튼은 `aria-label`.
- 토스트·배너는 `role="status"`/`aria-live="polite"`. 언어 바꾸면 `<html lang>`.
- **간편 모드**: `simple: true` 기능만 보임. 보이는 기능은 버튼 ≥ 56px, 글자 ≥ 16px, 선택지 3개 이하.
- **키오스크**: 줌 1.25. 입력은 이름 정도까지만 (긴 글 입력 기능 금지). `guest:reset` 시 기능 상태 전부 비움.
  키오스크에서 하는 기능(WP-01 이름 체크인 등)은 30초 안에 끝나야 함.
