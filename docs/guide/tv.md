# 📺 마을 TV — 신랑·신부용 안내

**무엇**: 마을 호숫가에 TV가 서고 (결혼식 전부터 · 당일까지), 두 사람이 넣은 유튜브 영상(생중계든 미리 만든 영상이든)이 그 안에서 나와요.

**준비 (결혼식 전 아무 때나)**
1. 유튜브에서 생중계를 예약하거나 영상을 올리고 주소를 복사 (`youtube.com/live/…` 또는 `youtu.be/…`).
   - 영상이 "퍼가기 허용"이어야 해요 (유튜브 스튜디오 → 영상 → 세부정보 → 퍼가기 허용).
   - `@채널이름` 주소는 안 돼요 → 생중계 페이지의 `youtube.com/live/…` 주소를 쓰세요.
2. `admin.html` → ⚙️ 설정 → "마을 TV (유튜브)" 줄을 펼쳐 주소 붙여넣기 → "✓ 유튜브 영상"이 보이면 **💾 저장** → **▶ 미리보기**로 확인.
3. 스위치는 처음부터 켜져 있어요. **결혼식 전부터** 마을 호숫가에 TV가 서 있고, 주소를 넣기 전에는 "📺 곧 방송이 시작돼요"가 나와요 (주소를 넣으면 결혼식 전에도 그 영상이 나와요). TV를 아예 없애려면 **끄기**.
4. 리허설: 마을 주소 뒤에 `?phase=live` (예: `village.html?phase=live`).

**당일**
- 식장 TV: 소리 **끈 채로** 자동 재생. 화면을 **한 번 클릭 = 소리 켜기/끄기**, **두 번 클릭 = 전체화면**(다시 두 번 = 원래대로).
- 🤫 조용 모드를 켜면 TV 소리가 꺼져요 (다시 켜려면 TV를 한 번 클릭).
- 하객 폰: "▶ 눌러서 보기"를 눌러야 재생(데이터 절약). 아래 바 `📺 TV`를 누르면 화면이 TV 쪽으로 가요. 두 번 탭하면 전체화면 (아이폰은 영상의 ⛶ 버튼).
- 체크 2개: "식장 TV 화면에서 바로 재생"을 끄면 TV에도 ▶ 포스터 · "하객 폰 마을에도 보이기"를 끄면 폰에는 안 나와요.

**끄면 / 주소를 지우면**: TV가 바로 사라져요 (전체화면이었으면 빠져나와요).
**문제가 생기면**: 스위치를 끄세요. 나머지 마을은 그대로예요. 영상이 "재생할 수 없음"이면 유튜브의 퍼가기 허용 · 공개 범위(공개 또는 일부 공개)를 확인하세요.
