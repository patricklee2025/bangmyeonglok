# 🎯 양가 섞이기 빙고 — 신랑·신부용 안내

**무엇**: 신랑측·신부측 하객이 **서로 말을 걸게 만드는** 4×4 빙고예요. 미션 일부는 다른 쪽 하객의 4글자 **하객 코드**를 받아야 해서 자연스럽게 섞여요.
한 줄을 완성하면 TV에 "🎯 ○○님 빙고!"가 뜨고, 그 하객 캐릭터 머리에 **왕관**이 생겨요. TV 오른쪽에 빙고 순위(상위 3명).

## 켜기 (결혼식 전에 미리)
1. `admin.html` → ⚙️ 설정 → "양가 섞이기 빙고" 줄 → **기본으로 켜져 있어요** (2026-10-08부터 · 끄려면 스위치를 **꺼짐**으로). 하객 화면에는 결혼식 당일(live)에만 보여요.
2. **🎯 빙고** 탭 → 미션 24개 중 맞지 않는 것은 **끄기** 체크 → 💾 저장. (최대 8개까지 — 카드 16칸을 채워야 해서)
   ⚠️ 미션을 바꾸면 모든 하객의 카드가 다시 섞여요 → **행사 전에만** 바꾸세요.
   하객이 한쪽만 있으면 "신랑측/신부측 코드" 미션 옆에 "⚠ 지금 하객으로는 할 수 없어요"가 떠요.

## 하객은 어떻게 하나요
- 방명록 완료 화면(또는 다시 왔을 때 "내 사진·리모컨") → **🎯 빙고 · n줄 · d/16** 줄 → 카드
- 카드 위에 **내 코드**(입장권·카드와 같은 4글자) — 다른 하객에게 알려 주기
- 칸 종류
  - 🤝 코드 칸: 조건에 맞는 하객의 코드를 입력 (예: 신랑측 하객, 나와 다른 쪽 하객)
  - 📷 자동 칸: 사진 올리기 · TV 리모컨 · 투표를 하면 저절로 ✓
  - ✋ 완료 칸: "완료했어요!" → "정말 완료했나요?" → ✓ (양심 체크)
- 폰 마을에서는 아래 버튼 줄의 🎯 (다른 기능 버튼이 있으면 "⋯" 안)
- 같은 하객이면 폰을 바꿔도 같은 카드, 도장도 합쳐져요. 어르신 간편 모드·키오스크에는 안 나와요.

## 결혼식 날 관리자
- **🎯 빙고** 탭: 전체 순위(줄 · 칸) · 미션별 완료 수 · 테스트 기록 **삭제**(두 번 눌러 확인)
- 투표가 TV에 떠 있는 동안에는 빙고 순위가 잠깐 숨고, 투표를 내리면 다시 나와요.

## 백업
**⬇ 전체 백업(ZIP)** 안에 `f-bingo/bingo.json` (하객별 완료 칸 · 줄 수).

## 끄면
⚙️에서 스위치를 **꺼짐**으로 → 카드·왕관·순위가 바로 사라져요. 기록은 그대로 남아요.
