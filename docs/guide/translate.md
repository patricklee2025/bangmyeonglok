# 🌐 덕담 자동 번역 — 신랑·신부용 안내

**무엇**: TV 아래 티커에 하객 덕담이 나올 때, **한국어 덕담에는 영어를, 영어 덕담에는 한국어를** 둘째 줄에 보여 줘요. 양가가 서로의 축하를 읽을 수 있게!
외부 서비스·비용 없이 **크롬 브라우저 내장 번역**(데스크톱 Chrome 138 이상)을 쓰고, 관리자 화면에서 미리 번역해 두거나 직접 고칠 수 있어요.

## 켜기
`admin.html` → ⚙️ 설정 → "덕담 번역" 줄 → **기본으로 켜져 있어요** (2026-10-08부터 · 끄려면 스위치를 **꺼짐**으로). TV에는 결혼식 당일부터 보여요.
⚙️ 기능 설정의 "TV 티커에 번역 줄 보이기"로 TV 줄만 끌 수도 있어요.

## 미리 번역해 두기 (추천 — 결혼식 전에도 돼요)
1. **노트북 크롬**으로 `admin.html` → **🌐 번역** 탭
2. "번역을 시작하려면 버튼을 눌러주세요"가 보이면 **🌐 번역 준비하기** → 번역 모델 내려받기(처음 한 번)
3. **🤖 빈 번역 모두 채우기** → 하객 덕담이 한꺼번에 번역돼 저장돼요
4. 어색한 번역은 칸에서 고치고 **저장** → "직접"으로 표시되고, 다시 "모두 채우기"를 눌러도 바뀌지 않아요
5. 결혼식 날 이 화면을 켜 두고 **새 방명록 자동 번역**을 체크하면 새로 온 덕담도 바로 번역돼요

## 결혼식 날 TV
- 저장된 번역이 있으면 그걸, 없으면 **TV 노트북 크롬이 즉석에서** 번역해요 (저장은 안 함).
- TV에 "🌐 번역을 켜려면 화면을 한 번 클릭해주세요"가 뜨면 화면을 한 번 클릭 → 모델 내려받기.
- **리허설에서 꼭 확인**: TV 노트북에서 `village.html?tv=1&phase=live`로 열어 번역 줄이 나오는지 보고, 끝나면 `village.html?tv=1&phase=auto`로 다시 여세요. 모델은 브라우저에 남아요.
- 하객이 덕담을 고치면(관리자 ✏️) 예전 번역은 "원문이 바뀜"이 되고 TV는 새로 번역해요.
- "신랑·신부에게만" 덕담과 이모지만 있는 덕담은 번역하지 않아요.
