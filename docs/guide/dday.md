# ⏳ D-day 마을 — 신랑·신부용 안내

**무엇**: 결혼식 **전에**(사전 입주 기간) 마을을 열면 "아직 공사 중인 결혼식 마을"이 보여요.
남은 날짜에 따라 공사가 조금씩 진행되고, 미리 입주한 하객들이 돌아다녀요. 다시 와 볼 이유가 생겨요.
데이터는 저장하지 않아요 (마을에 있는 하객 수만 셉니다).

## 켜기 (사전 입주 오픈 날, 예: 12/1 — 사전 입주와 같이)
`admin.html` → ⚙️ 설정 → "D-day 마을" 줄 → **기본으로 켜져 있어요** (2026-10-08부터 · 끄려면 스위치를 **꺼짐**으로).
설정할 것은 없어요. 날짜는 `config.js`의 결혼식 날짜(2027-04-10)로 저절로 계산돼요.

## 어디에 보이나요
- **하객 첫 화면**: 맨 위 작은 칩 "💒 결혼식까지 D-130"
- **폰 마을**: 위쪽 가운데 한 줄 "D-130 · 입주민 18명"
- **노트북 · TV 마을**: 왼쪽 위 레벨 패널 아래 "결혼식까지 / D-130 / 2027.04.10 (토) / 입주민 18명"
- **마을 안**: 제단 왼쪽 앞 나무 표지판에 D-숫자

## 공사 단계 (남은 날짜 기준, 매일 오전 6시에 하루씩 줄어요)
| 남은 날 | 마을 모습 |
|---|---|
| 61일 이상 | 터 닦기 — 제단 양옆 비계, 마당에 나무 상자 3개, "🚧 공사 중" 표지판 |
| 31–60일 | 기둥 세우기 — 오른쪽 비계 + 사다리, 상자 2개 |
| 8–30일 | 장식 달기 — 비계 치움, 광장 위 깃발 줄 |
| 2–7일 | 마무리 — 깃발 줄 + 카펫 양옆 화분 4개 |
| 1일 (전날) | 준비 완료 — "내일 만나요! 🎉" 현수막 |

## 결혼식 날
따로 할 일 없어요. 당일 **오전 6시**(본식 페이즈 시작)가 되면 공사 소품·칩·패널이 **저절로 사라지고** 결혼식 마을이 돼요.
(열려 있는 TV 화면도 새로고침 없이 바뀌어요.)

## 리허설 · 확인
- 주소 뒤에 `?ff=dday` 를 붙이면 켜기 전에도 미리 볼 수 있어요. 예: `village.html?ff=dday`
- 결혼식 당일 리허설(`?phase=live`) 중에는 안 보이는 게 정상이에요.

## 끄면
⚙️에서 스위치를 **꺼짐**으로 → 공사 소품·표지판·칩·패널이 바로 사라져요. 저장된 데이터가 없어서 다시 켜도 그대로 이어져요.
