# 📶 오프라인 대비 — 신랑·신부용 안내

**무엇**: 식장 와이파이가 끊기거나 느려도 **방명록·마을 화면이 열리게** 해 줘요(앱 껍데기를 기기에 저장 = 서비스워커).
Firestore가 원래 하는 오프라인 저장(쓰기 대기열)과 합쳐져, 끊긴 동안 쓴 방명록은 **연결되면 자동으로 전송**돼요.
배포 직후에도 옛 화면에 갇히지 않도록 **페이지·JS는 항상 인터넷 먼저**(3초 안에 답이 없을 때만 저장본)로 열어요.

## 켜기
1. `admin.html` → ⚙️ 설정 → "오프라인 대비" 줄 → **기본으로 켜져 있어요** (2026-10-08부터 · 끄려면 스위치를 **꺼짐**으로).
2. 하객이 **한 번** 인터넷으로 열어 두면, 그 기기는 그다음부터 끊겨도 열려요. (청첩장 QR로 미리 열어 본 하객은 이미 준비 완료)
3. 데모(`?demo=1`)와 내 컴퓨터(localhost)에서는 등록하지 않아요 — 시험할 땐 주소에 `?sw=1`.

## 결혼식 날
- 끊기면 하객 화면에 "인터넷이 끊겼어요. 작성한 내용은 연결되면 자동으로 보내요", 다시 붙으면 "다시 연결됐어요".
- TV는 원래 있던 연결 배너를 그대로 써요. TV·키오스크는 밤새 켜 두면 새 배포가 **새로고침할 때** 적용돼요.

## 문제가 생기면 (옛 화면이 계속 보일 때)
1. 그 기기에서 주소 끝에 **`?nosw=1`** 을 붙여 한 번 열기 → 저장본 삭제 + 해제 ("오프라인 저장을 지웠어요")
2. 관리자 ⚙️에서 스위치를 **꺼짐**으로 → 각 기기가 다음에 열 때 스스로 해제
3. 그래도 안 되면 **킬스위치**: `tools/sw-killswitch.js` 를 `public/sw.js` 로 덮어써서 다시 배포 → 모든 기기가 다음 방문 때 스스로 해제·캐시 삭제·새로고침

## 끄면
⚙️에서 스위치를 **꺼짐**으로 → 각 기기에서 다음에 열 때 서비스워커 해제 + 저장본 삭제. 그 뒤로는 평소처럼 인터넷으로만 열려요.

**리허설에서 꼭**: 아이폰·안드로이드로 한 번 열기 → 비행기 모드 → 다시 열기 · 관리자 Google 로그인(팝업) 정상인지 확인.
