# 🎵 8비트 BGM + 효과음 — 신랑·신부용 안내

**무엇**: TV 마을에서 게임 같은 8비트 배경음악과 효과음이 나와요. 음원 파일 없이 브라우저가 직접 합성하고,
곡은 공개 저작물(바그너·멘델스존·슈트라우스·파헬벨의 유명한 첫 주제만 짧게) + 자작 루프 3곡이에요.
**기본은 꺼짐**이고, 켜도 작게 나와요. 소리는 **TV에서만** — 하객 폰에서는 아무 소리도 안 나요.

## 켜기
1. `admin.html` → ⚙️ 설정 → "8비트 BGM" 줄 → 스위치를 **켜짐**으로 (음악은 리허설에서 정하도록 기본 꺼짐이에요).
2. 같은 줄의 세부 설정에서
   - **🎵 배경음악** · **🔔 효과음** 체크 (각각 따로)
   - **볼륨** 슬라이더 (기본 35%)
   - **곡 고정**: "자동"이면 아래 규칙대로, 곡을 고르면 그 곡만 반복
   - **▶ 미리 듣기**: 관리자 컴퓨터에서 고른 곡을 10초 (자동이면 '잔치 날')
3. TV 화면은 브라우저 규칙상 **한 번 클릭**해야 소리가 나요 → 화면에 "🎵 음악을 켜려면 화면을 한 번 클릭해주세요"가 떠요.

## 자동 선곡
| 언제 | 곡 |
|---|---|
| 결혼식 전 · 끝난 뒤 · 기념일 | 마을의 아침 |
| 결혼식 당일 낮 / 밤(N 키 또는 저녁 7시 이후) | 잔치 날 / 청사초롱 밤 |
| 식순 "신부 입장" | 결혼 행진(바그너) 1번 → 다시 기본 곡 |
| 식순 "행진" | 결혼 행진곡(멘델스존) 1번 |
| 식순 "식사" | 캐논(파헬벨) 반복 |
| 식순 "첫 댄스" | 아름답고 푸른 도나우 반복 |
| 🤫 조용 모드 | 멈춤 (곡 고정이어도 멈춤) → 풀리면 기본 곡 |

> 기본 식순에서 **신부 입장은 조용 모드**라서 TV 음악이 멈춰요(식장 음악이 우선). TV로 바그너를 틀고 싶으면
> 📋 식순 탭에서 신부 입장의 "조용 모드"를 끄세요.

## 효과음 (🔔 켰을 때만)
새 하객 도착 징글(2초에 1번) · 리모컨 반응 블립(0.5초에 1번) · 빙고 줄 완성 팡파르 · 투표 결과 북+화음 · 온도계 이정표 화음 · 부케/단체사진 북 굴리기.
레벨 업은 원래 있던 차임만 울려요.

## TV에서 바로
- **U 키**: 이 TV만 음악 켜기/끄기 (설정은 그대로, 새로고침하면 설정값으로 돌아가요)

## 끄면
⚙️에서 스위치를 **꺼짐**으로 → 즉시 정지. 기본이 꺼짐이라 켜지 않으면 아무 영향 없어요.

**리허설에서 꼭**: TV 스피커/HDMI로 7곡을 들어 보고("그 곡처럼 들리는지"), 식장 음향과 같이 틀어 음량을 맞추세요.
