# ⚙️ 설정 화면 보는 법 (2026-10 개편)

`admin.html` → **⚙️ 설정** 탭.

## 한눈에
- **맨 위 한 줄** — 지금이 언제인지 ("지금은 결혼식 전이에요 · D-184", 당일엔 "오늘은 결혼식 날이에요 💒").
- **기능 카드** — 언제 쓰는 기능인지에 따라 세 묶음으로 나뉘어요.
  - 📅 **결혼식 전부터** — 청첩장을 받은 하객이 지금부터 보는 기능
  - 💒 **결혼식 당일** — 켜 두기만 하면 4월 10일에 자동으로 나타나요
  - 🎁 **결혼식 후** — 결혼식이 끝난 뒤를 위한 기능
- 아직 만들지 않은 기능은 각 묶음 끝 **🔜 준비 중** 안에 접혀 있어요.

## 카드 한 장 읽기
| 보이는 것 | 뜻 |
|---|---|
| 스위치 **켜짐 / 꺼짐** | 누르면 바로 저장되고, 하객 화면에 1초 안에 반영돼요 |
| ✅ 켜짐 — 지금 하객에게 보여요 | 지금 하객 화면에 나와요 |
| ⏰ 본식 당일에 자동으로 나타나요 | 켜져 있지만 아직 때가 아니에요. 당일에 저절로 나와요 |
| ⏸ 꺼짐 — 켜면 바로 보여요 | 꺼 둔 상태 |
| 🛡 본식 안전 모드라 잠시 꺼짐 | 안전 모드를 끄면 돌아와요 |
| **기본값으로** (밑줄 글씨) | 직접 바꾼 기능에만 보여요. 누르면 처음 상태로 돌아가요 |
| ▶ ⚙️ 기능 설정 | 그 기능만의 설정 (예: TV 주소, 온도계 목표) |
| ⛔ 이번 세션 꺼짐 | 그 화면에서 문제가 생겨 잠시 껐어요. 새로고침해 보세요 |
| 작은 회색 글씨 `WP-05 · live` | 개발용 이름 — 신경 쓰지 않아도 돼요 |

## 🛠 고급 설정 (맨 아래, 접혀 있음)
평소엔 열 필요가 없어요.
- **페이즈 강제** — 비상용. 리허설은 주소 뒤에 `?phase=live` 를 붙이세요 (그 탭만 바뀜).
- **🛡 본식 안전 모드** — 당일 문제가 생기면 '본식 안전' 표시가 없는 기능을 한 번에 꺼요. 맨 위 라이브 패널에도 같은 버튼이 있어요.
- **모든 기능 기본값으로** — 세 번 눌러야 실행돼요. 켜고 끈 기록만 지워지고, 각 기능 설정(TV 주소 등)은 그대로예요.
