# 🃏 내 픽셀 카드 — 신랑·신부용 안내

**무엇**: 하객이 **내 캐릭터 + 내 덕담 + 픽셀 마을 배경**이 담긴 카드 이미지(1080×1350, 인스타그램 게시물 비율)를 저장하고
카톡·인스타에 공유해요. 결혼식 기념품이자 자연스러운 홍보물이에요. 카드 오른쪽 아래 QR을 찍으면 마을에서 그 하객의 캐릭터가 열려요.

## 켜기
`admin.html` → ⚙️ 설정 → "내 픽셀 카드" 줄 → **기본으로 켜져 있어요** (2026-10-08부터 · 끄려면 스위치를 **꺼짐**으로). 설정할 것은 없어요.
사전 입주(12/1)와 같이 켜면 결혼식 전에도 "결혼식 날 만나요!" 카드를 만들 수 있어요.

## 하객은 어떻게 쓰나요
- **방명록을 쓴 직후 화면**(또는 다시 왔을 때 "내 사진·리모컨" 화면): "🃏 내 픽셀 카드" 줄 → 카드 미리보기
- 배경 3가지: ☀️ 낮 · 🌇 노을 · 🌙 밤
- **💾 저장 · 공유**: 아이폰·안드로이드는 공유 창(카톡·인스타·사진 저장), 컴퓨터는 PNG 파일로 저장
- **폰 마을**: 아래 버튼 줄의 🃏 (다른 기능 버튼이 있으면 "⋯" 안에 있어요)

## 카드에 들어가는 것
- 하객 이름 · 신랑측/신부측/양가 · 덕담(최대 3줄, 길면 "…")
- 음성만 남긴 하객: "🎤 음성 메시지를 남겼어요"
- **"신랑·신부에게만" 체크한 덕담은 카드에 절대 안 나와요** → "💌 신랑·신부에게만 마음을 전했어요"
- 날짜에 따라 한 줄: 결혼식 전 "결혼식 날 만나요!" · 당일 "함께 축하해요!" · 이후 "함께해 주셔서 고마워요"
- 지환 ♥ 선경 · 2027.04.10 · 하객 코드(입장권과 같은 4글자)

## 데이터
새로 저장하는 것은 없어요 (하객 본인의 방명록을 한 번 읽어서 그림만 그려요).

## 끄면
⚙️에서 스위치를 **꺼짐**으로 → 카드 줄·버튼이 바로 사라져요. 이미 저장한 카드 이미지는 하객 폰에 그대로 남아요.
