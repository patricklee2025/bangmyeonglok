# 🗳 실시간 투표 — 신랑·신부용 안내

**무엇**: 식사 시간 등에 관리자가 투표를 열면 하객이 폰으로 바로 참여하고, TV 오른쪽에 실시간 막대그래프가 자라요.
"닫고 결과 발표"를 누르면 TV에 "🗳 결과: ○○!" 배너가 나와요.
종류 2가지: **보기 선택**(보기 최대 8개) · **하객 뽑기**(예: 오늘의 베스트 드레서 — 하객 중 1명).

## 켜기 · 미리 준비 (결혼식 전, 예: D-30)
1. `admin.html` → ⚙️ 설정 → "실시간 투표" 줄 → **기본으로 켜져 있어요** (2026-10-08부터 · 끄려면 스위치를 **꺼짐**으로).
2. **🗳 투표** 탭 → **＋ 새 투표**: 질문(한국어·영어) · 종류 · 보기(한국어·영어) → 💾 저장 → "초안"으로 저장돼요.
   빨리 시작하려면 **예시 질문 3개 넣기** → 두 사람이 처음 만난 곳 · 베스트 드레서 · 신혼여행지 (보기는 꼭 고쳐 주세요).
3. 결혼식 전에도 투표 탭은 열려요. 하객 화면에는 결혼식 당일(live)에만 보여요.

## 결혼식 날
- 관리자 화면 위쪽 **라이브 슬롯**의 큰 버튼 하나로 진행해요:
  **▶ 다음 투표 열기** (초안 중 맨 위) → 하객 폰 완료 화면에 투표 카드 · 폰 마을엔 🗳 버튼 · TV 오른쪽 막대
  → **■ 닫고 결과 발표** → TV 배너 + 결과 막대, 하객 폰엔 결과 카드 → **결과 내리기**로 TV에서 치우기
- 하객은 투표한 뒤 2초가 지나면 **다른 걸로 바꾸기**가 돼요 (열려 있는 동안).
- 동점이면 전부 1위예요 ("🗳 결과: A, B!"). 하객 뽑기 1위는 TV 마을에서 캐릭터가 반짝이며 점프해요.
- 투표 탭에서 **삭제**는 두 번 눌러야 지워져요 (그 투표의 표도 함께 지워짐).

## 백업
관리자 **⬇ 전체 백업(ZIP)** 안에 `f-poll/polls.json` · `f-poll/votes.json` (투표와 표 전부).

## 끄면
⚙️에서 스위치를 **꺼짐**으로 → 하객 카드·폰 버튼·TV 패널이 바로 사라져요. 투표·표 데이터는 그대로 남아요(백업에도 포함).
