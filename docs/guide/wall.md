# 💌 방명록 모아보기 — 신랑·신부용 안내

**무엇**: 방명록을 쓴 하객이 다른 하객들의 방명록(이름 · 캐릭터 · 메시지)을 폰에서 읽을 수 있어요. 사진과 음성은 지금처럼 두 사람만 봐요.

**켜기·끄기**: 처음부터 켜져 있어요. 끄려면 `admin.html` → ⚙️ 설정 → "방명록 모아보기" → 스위치를 **꺼짐**으로.

**하객에게 보이는 곳**
- 방명록을 다 쓴 화면 · 다시 들어온 "내 사진·리모컨" 화면에 `💌 다른 하객 방명록 보기` 줄 → 최신순 목록, 신랑측/신부측/양가로 거르기
- 폰 마을(방명록을 쓴 폰)에서 캐릭터를 누르면 그 사람의 방명록 · 아래 바 `💌 방명록` → 전체 목록
- 식장 TV와 키오스크에는 없음

**"💌 신랑·신부에게만 보여주기"** (작성 화면, 이 기능과 상관없이 항상 있음)
- 체크한 메시지는 다른 하객 · TV · 이 목록 어디에도 본문이 안 나오고 "💌 신랑·신부에게 마음을 전했어요"로만 보여요.
- 두 사람은 관리자 화면 카드(🔒 표시)와 백업(CSV · JSON)에서 읽을 수 있어요. 하객이 쓴 그대로라 수정은 안 돼요.
- ⚠️ 이 기능은 **규칙 v4를 게시한 뒤**에만 동작해요 (README · 03 §9).

**끄면**: 줄 · 버튼 · 목록이 바로 사라져요. 방명록 데이터는 그대로예요.

**미리 보기(데모)**: `index.html?demo=1&ff=wall` 에서 방명록을 쓰고 완료 화면의 💌 줄을 눌러 보세요.
