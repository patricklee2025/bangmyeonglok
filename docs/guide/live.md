# 📋 식순 라이브 — 신랑·신부(·도우미)용 안내

**무엇**: 도우미가 관리자 화면에서 식순을 **"다음 ▶"**으로 넘기면, TV 마을과 하객 폰 마을이 그 순간에 맞는 **장면**을 연출하고
화면 위에 지금 순서("📋 반지 교환")를 보여 줘요. 서약·반지처럼 엄숙한 순간엔 자동으로 **조용 모드**(배너·소리·불꽃 멈춤).

## 켜기 · 식순 준비 (결혼식 전에)
1. `admin.html` → ⚙️ 설정 → "식순 라이브 모드" 줄 → **기본으로 켜져 있어요** (2026-10-08부터 · 끄려면 스위치를 **꺼짐**으로).
2. **📋 식순** 탭: 기본 식순 16개(하객 입장 → … → 감사 인사)를 실제 식순에 맞게
   - ▲▼ 순서 · **사용** 체크(폐백은 기본 꺼짐) · 이름(한/영) · 장면 · 조용 모드 · 함께 보낼 이벤트(단체사진·부케·불꽃) · 배너 문구 → **💾 식순 저장**
   - 망가졌으면 **기본 식순으로**(두 번 눌러 확인)
3. 관리자 화면은 결혼식 전에도 열려요. 리허설은 TV 주소에 `?phase=live`.

## 결혼식 날 (도우미)
- 관리자 화면 위쪽 큰 버튼 **다음 ▶ {다음 순서}** 하나만 누르면 돼요 (2초 동안 잠겨 연타 방지).
- 실수로 넘겼으면 **◀ 이전** (장면 없이 제목만 되돌림) · **전체 식순**을 펼쳐 바로 고를 수도 있어요.
- **📢 한 줄 공지**: 한/영 입력 → **띄우기** → TV·폰 위쪽에 노란 줄로 표시 · **내리기** (다음 순서를 누르면 저절로 내려감)
- TV를 새로고침해도 이미 지난 장면은 다시 하지 않아요(제목·조용 모드만 복원).

## 장면 (12가지)
환호 · 신부 입장(카펫 걷기) · 고요 · 반지 반짝 · 하트 폭발+색종이 · 좌우 흔들기 · 행진 · 잔칫상으로 · 건배 점프+불꽃 · 첫 댄스 · 케이크 · 절(폐백)

## 끄면
⚙️에서 스위치를 **꺼짐**으로 → 장면·제목이 사라져요. 이미 켜진 **조용 모드**는 관리자 화면의 조용 모드 버튼으로 끄세요.
