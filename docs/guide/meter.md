# 🌡 마음 온도계 — 신랑·신부용 안내

**무엇**: 하객들의 축하가 모일수록 TV 오른쪽 위(QR 아래) **마음 온도계**가 올라가요. 36.5℃(체온)에서 시작해 **100℃**면 "사랑이 끓어 넘쳐요" + 불꽃!
50℃ · 70℃ · 85℃ · 100℃를 처음 넘을 때마다 배너와 하트가 나와요. 하객이 리모컨·사진·빙고·투표에 참여할 이유가 돼요.

## 점수
하객 1명 10점 · TV에 보이는 사진 1장 5점 · 리모컨 반응 1번 1점 · 빙고 1줄 3점 · 투표 1표 2점

## 켜기 · 목표 맞추기 (결혼식 전에)
1. `admin.html` → ⚙️ 설정 → "마음 온도계" 줄 → **기본으로 켜져 있어요** (2026-10-08부터 · 끄려면 스위치를 **꺼짐**으로). TV에는 결혼식 당일(live)에만 보여요.
2. 같은 줄 **⚙️ 기능 설정** → **예상 하객 수**(기본 50명) → "지금 목표 = 1690점"처럼 자동 계산. 원하면 **목표 점수**를 직접 넣어도 돼요. 💾 저장 → 켜져 있는 TV에 바로 반영.
   - 하객 50명이 다 오고, 1명당 사진 2장·리모컨 6번·투표 3번쯤 하면 100℃가 되는 기준이에요. 리허설 때 너무 빨리/늦게 오르면 숫자를 조정하세요.

## 결혼식 날
따로 할 일 없어요. TV를 새로고침해도 이미 지난 이정표는 다시 축하하지 않아요. 조용 모드에서는 숫자만 오르고 배너·불꽃은 기다려요.
폰 마을에는 안 보여요 (폰은 하객 일부만 받아서 숫자가 TV와 달라지기 때문).

## 끄면
⚙️에서 스위치를 **꺼짐**으로 → 온도계가 바로 사라져요. 저장하는 데이터는 없어요.
