# 📸 픽셀 네컷 — 신랑·신부용 안내

**무엇**: 인생네컷처럼 폰 앞카메라로 **4장을 연속 촬영**해 픽셀 액자 네컷 사진을 만들어요. 하객이 저장·공유하고, 원하면 **TV 포토월**에도 올려요.

## 켜기
`admin.html` → ⚙️ 설정 → "픽셀 네컷" 줄 → **기본으로 켜져 있어요** (2026-10-08부터 · 끄려면 스위치를 **꺼짐**으로). 결혼식 당일과 이후에 보여요.

## 하객은 어떻게 하나요
- 방명록 완료 화면(또는 다시 왔을 때 "내 사진·리모컨") → **📸 픽셀 네컷**
- 액자 색(핑크·민트·밤) 고르고 **📸 촬영 시작 (4장)** → 3·2·1 → 찰칵 ×4 (2초 간격)
  - 카메라를 못 쓰면 **🖼 앨범에서 4장 고르기**
- 결과: 세로 네컷(이름·날짜·내 캐릭터 스티커) · **픽셀 효과** 켜기/끄기
  - **💾 저장 · 공유** → 폰 공유 창(카톡·인스타·사진 저장)
  - **📺 TV 포토월에 올리기** → 2×2 사진이 TV 폴라로이드로 (하객당 사진 5칸 중 1칸 사용)
- 화면을 나가면 카메라는 바로 꺼져요. 어르신 간편 모드·키오스크에는 안 나와요.

## 끄면
⚙️에서 스위치를 **꺼짐**으로 → 버튼이 바로 사라져요. 이미 TV에 올린 사진은 일반 사진과 같아요(관리자 "하객 스냅"에서 숨기기/삭제).
